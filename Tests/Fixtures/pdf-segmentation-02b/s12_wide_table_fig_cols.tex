\section{Methodology}
Our benchmark evaluates hierarchical layout recovery across heterogeneous scholarly templates. Each page is decomposed into running margins, spanning floats, and column-isolated body paragraphs before downstream numeric verification.

Architectural parameters are strictly audited: our reference encoder uses 3 layers, 4 attention heads, and a hidden width of 256 units across 19 datasets grouped into 4 task families, plus a small dataset (610) of PuzzleScript games with n = 1, 000 samples per split.

\newpage
\section{Dataset Construction}
Every archival PDF in our evaluation corpus is verified against reference word tokens extracted by independent layout tools. Running headers and footers are matched across page margins so that repeated journal titles never contaminate downstream passage retrieval.

For quantitative verification, numbers attached to dimensional units or count nouns are canonicalized before comparison, preventing cross-noun collisions when multiple quantities appear inside the same paragraph or table note.

\section{Experimental Results}
To assess the efficacy of FHBI, we evaluate our layout recovery pipeline on six diverse benchmark suites spanning both in-domain and out-of-domain distributions. Isolating wide floats before column partitioning preserves exact paragraph boundaries in the left column.
